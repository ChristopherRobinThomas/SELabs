# Software Engineering Lab Summer Semester 2023 Group B02
## Logging in
- You can create a new user(The username and password are not allowed to be empty). Here a new user is created on serversided. For this you need an Internet connection.
- When already created a user on another device, you can login with the same username and password. Your app will synchronize all data and keep both instances up-to-date.
- If you didn't log out last time you will skip the login part and will immediatly start in the home screen.
  
## Home Screen
- You can answer the questionnaire in the morning (07:00 - 11:00), noon (12:00 - 14:00), or evening (17:00 - 19:00). The questionnaire is limited to one answer per timeslot. Otherwise the button will be transparent.
- You can set a daily goal or create a custom daily goal.
- You can see the progress on the daily goal or can set it to done. The progress bar obviously only works for tasks like walk 5.000 steps. 
- You can open an overview which lists you all your recordings and interventions sorted by date.
- you can see the last five interventions/recordings at the bottom of the home screen.
  
## Data
- You can change the time frame in which you want to see the aggregated data. For this you can click the dates and select the dates in a calendar.
- You can choose between different plots. You can see the development of you mental health score, a bar graph which shows you how many interventions you did on each day and a pie chart which illustrates you chosing of the daily task.
  
## Interventions
- You can start a manual recording of the selected sensors using the "Play"-Button. Clicking it again will stop the recording.
- You can choose from multiple different interventions. Clicking on one will open up a new window where you can see a description and a video to describe the given exercise. Clicking on "Start" will start a recording in the background until you click "finish". You can also add a rating and additional notes you want to send to the researcher. 
- You can add own interventions. These only get a title and will also be added to the intervention list. 
  
## Settings
### Visual Settings
- You can change the app into dark/light mode.
- You can choose an app color (red/blue/green).
### Sensor Settings
- You can allow multiple sensors to be recorded. You can choose between GPS, Accelerometer and the Stepcounter.
### Notification Settings
- You can set you morning timer (07:00 - 11:00).
- You can set you noon timer (12:00 - 14:00).
- You can set you evening timer (17:00 - 19:00).
### Account Settings
- You can logout and keep your user on you device. The User will still be visible in the opening screen. To log in you then only need your password again.
- You can logout from this device completely. This will also remove your user from the opening screen. You account however will still be alive on the server. So you can log in later.
- You can completely delete all data associated with your account. This includes local files and all data saved online.
- You can rewatch the tutorial which is shown when creating a new user.

## Feature
- In the noon after the questionnaire a Digit Span Task is provided for additional data.
- When the answers of the questionnaire indicate that you feed unwell, we suggest a random interventions you can complete.
- We show a tutorial video which covers all the features in our app when creating a new user. This can be rewatched from the settings.
- All our data is saved online and offline to ensure that the app works offline while when possible we can upload the data to the researcher.
