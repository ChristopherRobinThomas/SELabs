# Software Engineering Lab Summer Semester 2023 Group B02
## Logging in
- you can create a user(The username and pasword are not allowed to be empty)
- you can login an existing user
- you will be automaticly logged in if you didn't log out
  
## Home Screen
- you can open the questionnaire if it's morning, noon, or evening and you didn't answer one in that time frame
- you can set an daily goal
- you can see the progress on the daily goal or can set it to done
- you can see all past interventions
- you can sell recent inteventions
  
## Data
- you can set an time frame, which you want to inspect
- you can then choose what you want to see(mental health score/number of interventions/distribution) 
## Interventions
- you can start recording your accelerometer
- you can add a personal intervention
- you can do an already added intervention 
  
## Settings
### Visual Settings
- you can change the app into dark/light mode
- you can choose an app color (red/blue/green)
### Notification Settings
- you can allow step counter, accelerometer, GPS for your devices
### Timer Settings
- you can set you morning timer (07:00 - 11:00)
- you can set you noon timer (12:00 - 14:00)
- you can set you evening timer (17:00 - 19:00)
### Account Settings
- you can logout and keep your user on you device
- you can logout from this device and keep the user globaly
- you can completly delte all data on online and localy on you device
- you can watch a video on how to use the app
